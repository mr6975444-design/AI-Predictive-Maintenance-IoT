# AI-Powered Predictive Maintenance for IoT Devices

## 📌 Project Overview

This project demonstrates an AI-powered predictive maintenance system for IoT devices using simulated sensor data.

The system uses temperature, vibration, and current measurements to predict whether a machine is operating normally or showing signs of potential failure.

Because physical industrial IoT hardware is not available, the project uses a simulated sensor dataset for development and demonstration.

---

## 🎯 Objectives

- Generate simulated IoT sensor data
- Clean and validate sensor data
- Extract relevant sensor features
- Train a machine-learning classification model
- Predict potential equipment failure
- Generate failure alerts
- Evaluate model performance
- Visualize sensor patterns and model results
- Build a GitHub-ready machine-learning project
